## 🚀 Deploy to Vercel in 5 Steps

### Step 1 — Get Your Anthropic API Key
1. Go to **console.anthropic.com**
2. Sign up / log in
3. Click **"API Keys"** → **"Create Key"**
4. Copy your key (starts with `sk-ant-...`)
5. Add $5 credit under **Billing**

---

### Step 2 — Create GitHub Account
1. Go to **github.com** → Sign up free
2. Verify your email

---

### Step 3 — Upload to GitHub
1. Click **"New repository"** (green button)
2. Name it: `sentinel-ai`
3. Set to **Public**
4. Click **"Create repository"**
5. Click **"uploading an existing file"**
6. Drag and drop the entire `sentinel-ai` folder contents
7. Click **"Commit changes"**

---

### Step 4 — Deploy on Vercel
1. Go to **vercel.com** → Sign up with GitHub
2. Click **"Add New Project"**
3. Select your `sentinel-ai` repository
4. Click **"Deploy"** — Vercel auto-detects React
5. Wait ~2 minutes → you get a live URL!

---

### Step 5 — Use Your App
1. Open your Vercel URL (e.g. `sentinel-ai.vercel.app`)
2. Paste your Anthropic API key when prompted
3. Your key is saved in your browser — you only enter it once per device
4. Hit **SCAN NOW** and enjoy live market intelligence!

---
